# Gshoppy v1

gadgets and accesories e commerce store

Focus on everyday gadgets, phone accessories, projector, charging gear, and smart-home products, with a clean modern storefront and a responsive web platform.

Start building the responsive storefront with the five categories, clean modern styling, product cards, and a slide-out cart as the first version.

This project was built with [Lovable](https://lovable.dev).
